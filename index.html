KToM — configuration requise 🎬

L'application n'a pas encore de clé API TMDB. Le propriétaire doit renseigner la clé directement dans le code source, puis redéployer le fichier.

  1. Créer un compte gratuit sur themoviedb.org et demander une clé API (v3 auth) dans Réglages → API.
  2. Ouvrir le fichier index.html et coller la clé dans la ligne const DEFAULT_API_KEY=''; (entre les guillemets).
  3. Enregistrer et redéployer le fichier. L'application démarrera automatiquement pour tout le monde.
